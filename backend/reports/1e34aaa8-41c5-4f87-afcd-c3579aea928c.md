## Output Format (Schema 13)

### index.json
```json
{
  "schema_version": "13",
  "commit": "<git hash or null>",
  "fingerprint": "<sha256>",
  "indexer_version": "2.0.0",
  "repo_path": "/absolute/path",
  "symbols": [
    {
      "symbol_id": "file.py::qualified_name",
      "kind": "function|method|class|constant|module",
      "name": "simple_name",
      "qualified_name": "Class.method",
      "file": "relative/path.py",
      "line_start": 10,
      "line_end": 20,
      "signature": "(arg: int) -> str",
      "is_async": false,
      ...
    }
  ],
  "references": [
    {
      "kind": "call|import|import_from|base_class",
      "caller": "symbol_id or <module>",
      "callee": "symbol_id",
      "file": "path.py",
      "line": 15
    }
  ],
  "failures": [
    {
      "file": "path.py",
      "stage": "read|parse",
      "line": 10,
      "column": 5,
      "reason": "SyntaxError",
      "message": "error details"
    }
  ]
}
```

### graph.json
```json
{
  "nodes": ["symbol_id1", "symbol_id2", ...],
  "edges": [
    {"from": "id1", "to": "id2", "kind": "call"}
  ],
  "unresolved": [
    {
      "reference": {...},
      "kind": "call",
      "reason": "no match|multiple matches"
    }
  ]
}
```

### bug_report.json
```json
{
  "bugs": [
    {
      "bug_id": "B001",
      "file": "path.py",
      "symbol": "function_name",
      "line_start": 10,
      "line_end": 20,
      "categories": ["test_failure"],
      "sources": ["pytest", "ruff"],
      "confidence": "confirmed",
      "verified": true,
      "evidence": ["Test: test_foo", "..."],
      "test_ids": ["test_file.py::test_foo"]
    }
  ],
  "count": 1
}
```

## Assumptions & Defaults

### Task 1 (Indexer)
- Fingerprint = sha256(all .py files + import_roots + schema_version)
- Git commit via `git rev-parse HEAD`, null if unavailable
- Cache files: `index_{fingerprint[:16]}.json`

### Task 2 (Graph)
- Module symbols have ID: `"file.py::<module>"`
- Bare name conflicts marked as unresolved "multiple matches"
- Import edges between module symbols

### Task 3 (BM25)
- Answer-key pattern: `backend/tests/answer_keys` in path
- Module chunks from docstring + limited source
- Test chunks excluded by default (configurable)

### Task 4 (Detection)
- Pytest timeout: 5 minutes for full run
- Ruff optional (skips if not installed)
- Verification test timeout: 60 seconds
- Proximity merge threshold: 3 lines
- Confidence: confirmed > multi-source > single-source

### Task 5 (Context)
- Graph depth: 2 hops
- BM25 top-k: 10 results
- Token budget: 12,000 tokens
- Fusion disabled by default
- Drop order: T6 → T5 → T4 → trim T2

### Task 6 (Orchestrator)
- LLM kill switch auto-enabled with --stop-after
- Run ID format: `r_YYYYMMDD_HHMMSS`
- Sequential execution (no parallelism)
