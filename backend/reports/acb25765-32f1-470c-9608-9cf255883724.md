## Assumptions and Defaults

### Task 1 Assumptions:
1. **Fingerprint calculation**: Uses existing `content_hash()` function which includes:
   - All .py file contents
   - Import roots configuration
   - Schema version
   - Excludes directories matching exclude_patterns

2. **Git commit**: Best-effort extraction using `git rev-parse HEAD`. If git unavailable or error occurs, commit is set to `null`.

3. **Cache location**: Uses existing cache_dir parameter, with cache files named `index_{fingerprint[:16]}.json`.

### Task 2 Assumptions:
1. **Module symbols**: Schema 13 includes module symbols with id `"file.py::<module>"`. Graph builder treats these as regular nodes.

2. **Lookup conflicts**: When bare name matches multiple symbols, marked as unresolved with reason "multiple matches".

3. **Import edges**: Created between module symbols. For `from X import Y`, also creates edge to specific symbol if found.

### Task 3 Assumptions:
1. **Answer key pattern**: Files containing `backend/tests/answer_keys` in their path (normalized to forward slashes) are excluded.

2. **Module chunks**: Schema 13 includes module symbols; BM25 builder treats these same as other symbols (chunks from module docstring + limited source).

3. **Searchable chunks**: By default, test chunks excluded from search (configurable in bm25_chunks.py).

### Config Defaults for Task 5 (Context Builder):
```yaml
context:
  graph_depth: 2          # Graph walk depth
  bm25_top_k: 10          # Top BM25 results to include
  fuse_scores: false      # Score fusion disabled by default
  token_budget: 12000     # Maximum tokens for context
```
